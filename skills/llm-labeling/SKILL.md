# LLM labeling

Use [DELM](https://center-for-applied-ai.github.io/delm/) for any LLM
labeling or structured extraction. Do not write a custom prompt loop,
schema validator, retry wrapper, or batch script for this.

How to define a schema, run an extraction, estimate cost, or evaluate
against labels is in the docs. Read them and use what DELM already
provides.

- Docs: <https://center-for-applied-ai.github.io/delm/>
- Getting started: <https://center-for-applied-ai.github.io/delm/getting-started/>
- GitHub: <https://github.com/Center-for-Applied-AI/delm>

Don't rewrite an llm labeling pipeline with DELM unless explicitly asked.
